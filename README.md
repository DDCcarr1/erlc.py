# erlc.py

erlc.py is an asynchronous wrapper for the Emergency Response: Liberty County/Police Roleplay Community API. It uses the API's v2 version to allow for **one** request to the API to get all the information you need, as well as the v1 for sending commands.

## Documentation

The erlc.py documentation can be found at our [GitHub Pages Site](https://erlc-py.github.io/). If you would like to contribute to the documentation, checkout the [documentation repository](https://github.com/erlc-py/erlc-py.github.io).


The documentation includes installation, usage, examples, and more.
